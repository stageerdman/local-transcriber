# Local Transcriber — known issues & TODOs

- [ ] Resumable transcription (shipped 2026-10-16): a job can be stopped any
      time and resumes from its checkpoint, auto-continuing on next launch even
      after a reboot. Verified via the unit suite + a real-engine stop/resume
      e2e + a full app auto-resume-on-launch integration, but NOT yet clicked
      through the real pywebview GUI window (rendering verified via a DOM stub).
      Optional follow-ups in updates/2026-10-16 resumable-transcription - OPEN/:
      file-missing "Locate file…" resume UX (currently such jobs are discarded
      at launch), inline Stop/Resume on Home cards (sidebar-only today), and the
      two-history-rows-per-resumed-job cosmetic.

- [ ] Multi-speaker transcripts: real UI click-through with actual multi-track
      audio not yet verified end-to-end. Covered by automated tests (32 passing
      via `pytest` from the project root), but not exercised through the app UI.
      See updates/2026-09-02 multi-speaker-transcripts - CLOSED/update v1.md.

- [ ] Real transcription progress works for Parakeet (chunk_callback) but NOT
      for the mlx-whisper backend, which has no progress hook and stays on the
      time-estimate bar. Real Whisper progress would require chunking the audio
      ourselves (quality tradeoff at chunk boundaries). See
      updates/2026-09-23 transcription-progress - CLOSED/.

- [ ] Track preview scrubbing (ffplay) works but has two known rough edges,
      both acceptable for a preview and only worth fixing if they annoy in real
      use (would likely mean a sample-accurate player = a small new dependency):
        * playhead is wall-clock from the seek point, so it can lead the actual
          audio by ffplay's ~0.2-0.3s startup latency (not sample-exact);
        * seeking restarts ffplay, so there's a tiny gap on each jump.
      Also: preview interactions aren't unit-tested through the real Tk canvas
      (canvas width isn't realized headless); verified via a manual/headless
      drive instead. See updates/2026-09-23 track-preview-scrubbing - CLOSED/.

- [ ] Parakeet chunking is fixed at 120s; smaller chunks would make the
      progress bar update more often (and are more memory-safe) at some extra
      overlap recompute. A knob to revisit if the bar's jumps feel too coarse.

- [ ] Web-UI rewrite (updates/2026-10-04 web-ui-rewrite - CLOSED/): new pywebview
      app is the default (`python -m app.main`; Tkinter fallback `app.main_tk`).
      Core loop works; remaining before closing the update:
        * Full real-app GUI transcribe-to-completion not yet confirmed end-to-end.
        * "Fix speakers" from a FINISHED transcript needs a non-destructive re-run
          (only pre-transcribe editing is wired).
        * Per-person language token in the UI is not passed to the worker (global
          language only).
        * Multiple dropped/picked files: only the first is detected/transcribed
          (no batch queue yet).
        * debug=True (devtools) still on in app/webview_main.py; retire Tkinter
          (app/main_tk.py, app/ui.py) once confident; prune dead prototype CSS.
      See the update's "▶ RESUME HERE" for the full picture.

- [ ] Polishing quality (updates/2026-10-09 polishing-research - CLOSED/): the
      benchmark winner is SHIPPED in src/polish.py (minimal-edit prompt +
      ~5-turn batches; beat the old prompt on readability AND faithfulness, no
      fabrication). Optional, not yet done:
        * high-assurance mode = 3-model edit-vote ensemble (marks unclear audio
          [nesrozumitelné], never guesses) as an optional toggle — safest but 3×
          cost + under-corrects; design in wiki.md §4e.
        * polish_text() (single-speaker plain text) still uses a large 6000-char
          chunk; shrinking toward the "moderate context" finding is untested.
        * confidence-gated correction (only touch low-confidence ASR spans) needs
          ASR logprobs the .md doesn't carry — an engine-level idea, out of scope.
      The LLM judge alone is unreliable for this (fooled by fluent paraphrase);
      trust the deterministic drift + direct reading. See the update's Resume
      notes.
